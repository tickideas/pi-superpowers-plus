## Phase 4 — SDD v6 rework (the big one; needs decisions first)

Upstream rewrote `subagent-driven-development` across ~30 commits (eval-tuned).
Fork's SKILL.md is 304 lines vs upstream's rebuilt version; this is a
merge-rewrite, not a patch.

### What upstream changed

1. **Merged task reviewer** (e08ad06): spec review + quality review collapse
   into ONE reviewer pass per task with two verdicts (spec ✅/❌ + quality
   approved/issues). `spec-reviewer-prompt.md` and
   `code-quality-reviewer-prompt.md` are deleted; `task-reviewer-prompt.md`
   replaces both.
2. **File handoffs** (4298eac): task briefs, implementer reports, and diffs
   move as files, not pasted text. New scripts (plain bash, platform-neutral):
   - `scripts/task-brief PLAN_FILE N` — extracts one task's text to a file
   - `scripts/review-package BASE HEAD` — commit list + stat + `diff -U10` to one file
   - `scripts/sdd-workspace` — resolves `.superpowers/sdd/` scratch dir
3. **Durable progress ledger** (4298eac, 93b8444):
   `.superpowers/sdd/progress.md` survives compaction; check at skill start,
   append on task completion; recover from `git log` if destroyed.
4. **Model discipline** (b42a232, 5e03007, cfe48c2, e97faaf): model is
   REQUIRED on every dispatch (omitted = inherits most expensive); turn-count
   beats token price (mid-tier floor for reviewers/prose implementers);
   cheapest tier for transcription tasks (plan contains complete code);
   final review pinned to most capable model.
5. **Reviewer-prompt hygiene** (8335498, 0974229, d55cdce, de4672b): never
   pre-judge findings ("do not flag", "at most Minor" = stop); constraints
   block copied verbatim from plan's Global Constraints; diff handed as file,
   never pasted; BASE recorded before dispatch (never `HEAD~1`).
6. **⚠️ verdict channel** (342f4e2, 16da215): reviewer reports "cannot verify
   from diff" items; controller resolves each before marking task complete.
7. **Pre-flight plan review** (b61b550): scan plan for contradictions before
   Task 1; batch all conflicts into ONE question to the human.
8. **Plan-mandated defects** (530476f): findings that conflict with plan text
   go to the human — never silently dismissed or silently "fixed".
9. **Fix-dispatch contract** (cc62053, c30d822): fixers re-run covering tests
   and append to the report file; final-review findings get ONE fixer with
   the complete list, not one per finding.
10. **Implementer prompt** (afbf0fc + file handoffs): TDD RED/GREEN evidence
    in report; report to file, return <15-line summary; focused tests while
    iterating, full suite once before commit.
